# PyBot - Simple Python Chatbot

## About the Project

PyBot is a simple rule-based chatbot developed using Python.
It can understand basic messages and provide predefined responses.

The project is suitable for beginners who are learning Python
programming and basic chatbot concepts.

## Features

- Greets the user
- Responds to "hello", "hi", and "hey"
- Answers "how are you?"
- Tells the chatbot's name
- Explains what it can do
- Responds to "thank you" and "thanks"
- Supports "bye", "exit", and "quit"
- Gives random responses for some questions
- Handles unknown questions

## Technologies Used

- Python 3
- Random module
- If-elif-else statements
- While loop
- Dictionary
- User input

## Requirements

You need:

- Python 3.x
- VS Code or another Python editor

No external libraries are required.
